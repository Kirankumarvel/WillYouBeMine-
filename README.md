## ✨ Features

- 💖 **Heart icon with beat animation** – sets the romantic mood instantly.
- 🎨 **Glittering particle background** – romantic, floating sparkles (canvas).
- 💕 **Floating hearts generator** – hearts rise from the bottom continuously.
- 🖱️ **Interactive mouse trail** – hearts follow your cursor.
- 🏃 **“No” button runs away** – moves to random positions on hover/click.
- 🎉 **Confetti explosion** – bursts of colorful confetti on “Yes”.
- 💬 **Hidden love message** – appears with animation after “Yes”.
- 📱 **Fully responsive** – works perfectly on mobile and desktop.
- 🎭 **Playful & witty messages** – cute notes after several failed “No” attempts.

## 🚀 How to Use

### Option 1: Open directly in browser
1. Download the `index.html` file.
2. Double-click it — works offline with all animations.

### Option 2: Host on GitHub Pages (for sharing)
```bash
git clone https://github.com/Kirankumarvel/WillYouBeMine-.git
cd WillYouBeMine-
# Make sure index.html is in the root folder
```
Then, go to your repository **Settings → Pages** → select branch `main` → save.  
Your page will be live at `https://your-username.github.io/WillYouBeMine-`

## 🎨 Customization

Want to personalize the proposal? Edit these parts inside `index.html`:

| Element                | What to change                                         |
|------------------------|--------------------------------------------------------|
| ✨ Title / Headline     | `<h1>` tag — "My Dearest" → her name / your pet name  |
| 💌 Question text        | `.question-text` — e.g., "Will you marry me?"         |
| 💖 Love message         | `#loveMessage` — romantic message after "Yes"         |
| 🎨 Background color     | `body` style — gradient colors                        |
| 💕 Floating heart rate  | `setInterval` — make hearts float faster/slower       |

You can also replace emojis and add custom images.
